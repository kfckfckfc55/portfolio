Mọi thay đổi được lưu nháp tự động trên trình duyệt này. Bấm Xem trước để xem web trông thế nào.

  1. Ô có 2 cột VI | EN: cột EN có thể bỏ trống, web sẽ dùng tiếng Việt.
  2. Để trống ô nào thì phần đó tự ẩn hoặc hiện khung thay thế.
  3. Xong thì bấm Đăng lên web (lần đầu cần thiết lập GitHub, chỉ mất 2 phút).
Muốn bỏ bản nháp và lấy lại nội dung đang chạy trên web?

Đăng lên web qua GitHub

Trang này sẽ lưu thẳng data.js và ảnh vào kho GitHub của bạn. Khoảng 1 phút sau web tự cập nhật.

Tạo mã truy cập (token), chỉ cần làm 1 lần:
  1. Mở github.com/settings/personal-access-tokens/new
  2. Đặt tên tuỳ ý, Expiration chọn thời hạn bạn muốn.
  3. Repository access → Only select repositories → chọn kho portfolio.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Bấm Generate token, sao chép mã và dán vào ô dưới.
Mã chỉ được lưu trên trình duyệt này, không gửi đi đâu khác ngoài GitHub.

Đã tải xuống data.js

Cập nhật web thủ công:

  1. Vào kho GitHub → mở file data.js → bấm ✏️ → xoá hết, dán nội dung file vừa tải → Commit changes.
    (hoặc Add file → Upload files → kéo file data.js vào → Commit)
